- Streamlit
- KNN
- TF-IDF / CountVectorizer
- Scikit-learn

## Features

- Song recommendations
- Album covers
- Spotify links
- Dark Spotify-style UI

## Tech Stack

- Python
- Pandas
- Scikit-learn
- Streamlit
